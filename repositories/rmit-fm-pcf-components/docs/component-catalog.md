# PCF Component Catalog

No custom component is approved yet.

For each future component record:

| Field | Required content |
|---|---|
| Component | Namespace and constructor |
| Requirement | FR/NFR ID and acceptance criterion |
| Host | Model-driven app, canvas app or both |
| Standard-control gap | Why a supported standard control is insufficient |
| Inputs/outputs | Manifest properties and data classification |
| Accessibility | Keyboard, screen reader, contrast and responsive evidence |
| Performance | Bundle size and render/API-call measurements |
| Version | Component and owning solution version |
