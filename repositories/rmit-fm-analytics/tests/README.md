# Analytics Tests

Add automated and reproducible checks for:

- explicit measure results and unit handling;
- date/campus/building/asset filter behavior;
- positive and negative RLS cases;
- Bronze/Silver/Gold reconciliation to report totals;
- source-to-report freshness;
- visual render performance under a documented test profile.

Freshness and render time are separate measurements. Do not claim either SLA from code inspection.
