## Thứ tự đọc đề xuất

1. Đọc tổng quan để hiểu mục tiêu và phạm vi.
2. Đọc kiến trúc kỹ thuật để hiểu các module và luồng dữ liệu.
3. Đọc kiến trúc Dataverse Medallion để hiểu Environment, Solutions, Tables và processing flow.
4. Đọc thiết kế bảng để bắt đầu thiết kế schema/contract.
5. Đọc kế hoạch Dev để triển khai theo các bước D0–D9.
