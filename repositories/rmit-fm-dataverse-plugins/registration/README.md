# Registration Metadata

Source-control the declarative identity of plug-in steps and images here or in the unpacked unmanaged solution metadata generated by the approved toolchain.

Every registration must document:

- plug-in type and message;
- primary table and filtering Columns;
- stage, execution mode and order;
- pre/post images;
- impersonation requirement;
- idempotency/retry behavior;
- mapped requirement and test evidence.

Do not store environment GUIDs, connection details or secure configuration values.
