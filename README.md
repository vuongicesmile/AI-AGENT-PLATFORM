Production-ready AI agent backend experiments.

## GitHub → Gemini Notebook → GPT + local memory

The new [`agent_platform`](agent_platform/README.md) module provides:

- safe GitHub repository extraction;
- persistent PC-local SQLite/FTS5 memory;
- Markdown bundles for personal Gemini Notebook (NotebookLM);
- official Gemini Notebook Enterprise source sync;
- an MCP server for Codex and a private ChatGPT developer-mode plugin.
